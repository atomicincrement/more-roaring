# Improve on Roaring bitmaps using SIMD-friendly data structures.

* Read https://arxiv.org/pdf/1603.06549 or the tex equivalent.
* Read the docs of https://github.com/RoaringBitmap/roaring-rs
* Implement the paper using the interface of roaring-rs
* Look at the datastructure and generate stats for various densities of bitmap.
* Investigate using AVX512_BF to accelerate the existing algorithm and to improve the data structure.
